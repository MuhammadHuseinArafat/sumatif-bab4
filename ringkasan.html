02STRUKTUR KOMPUTER

Arsitektur Von Neumann

STORED-PROGRAM

Arsitektur ini terdiri dari CPU, Memory Unit, Input Device, Output Device, dan Buses. Dalam konsep Stored-Program, instruksi program disimpan di memori bersama data.

CU

Control Unit

Mengatur jalannya instruksi dan menerjemahkan instruksi sesuai Instruction Set CPU. CU juga menerjemahkan alamat simbolis ke lokasi memori dan mengirim sinyal kendali.

ALU

Arithmetic and Logic Unit

Menjalankan operasi aritmatika dan logika. Untuk membandingkan X dan Y, ALU menghitung X − Y lalu memeriksa apakah hasilnya 0.

REG

Register

Ruang kerja sementara yang sangat dekat dengan CPU untuk menyimpan data atau instruksi yang sedang diproses.

SET

Instruction Set

Kumpulan instruksi yang dipahami CPU. Kumpulan ini dapat berbeda bergantung pada jenis atau merek CPU.

i

Microcontroller sederhana untuk tugas tombol → lampu: bus adalah komponen yang paling tidak signifikan dibanding komponen lain karena pertukaran datanya sangat minimal.

03URUTAN KERJA CPU

Siklus mesin

WAKTU-I → WAKTU-E

CPU mengambil instruksi dan memahami perintahnya sebelum menjalankan operasi.

WAKTU-I · INSTRUKSIFetch → Decode
›
WAKTU-E · EKSEKUSIExecute → Store
TahapApa yang terjadi?Komponen yang berperan
FetchMengambil instruksi dari memori.Memory Unit / RAM dan CPU.
DecodeMenerjemahkan instruksi agar CPU mengetahui operasi yang diminta.Control Unit (CU).
ExecuteMenjalankan operasi, misalnya perhitungan atau logika.ALU atau unit CPU terkait.
StoreMenyimpan hasil ke register atau memori.Register / Memory Unit.

Mengapa Waktu-I lebih dulu?
CPU harus mengambil dan menerjemahkan instruksi sebelum tahu apa yang perlu dieksekusi.

Data masih tersedia di RAM?
Tahap Fetching dan Executing paling diuntungkan karena data sudah siap di memori cepat.

04CONTOH LANGKAH PROGRAM

Mr. Algo: 3 × 10 + 9

HASIL = 39

Data awal berada di kotak 1 = 3, kotak 2 = 10, dan kotak 3 = 9. Nilai di register menjadi ruang kerja selama operasi berjalan.

LangkahInstruksiKeteranganHasil
1LOAD kotak 1 → Register AAmbil angka 3.A = 3
2LOAD kotak 2 → Register BAmbil angka 10.B = 10
3MULTIPLY A × BALU mengalikan A dan B.A = 30
4LOAD kotak 3 → Register BAmbil angka 9.B = 9
5ADD A + BALU menjumlahkan hasil.A = 39
6STORE A → kotak 4Simpan hasil akhir.kotak 4 = 39

Nama instruksi dan format kolom dapat berbeda mengikuti contoh dari guru; urutan logikanya tetap sama.

05PENGELOLA KOMPUTER

Sistem Operasi

OS ≠ APLIKASI

Operating System (OS) mengelola perangkat keras, menyediakan antarmuka pengguna, dan membantu komponen bekerja efisien. Game dan browser adalah aplikasi yang berjalan di atas OS, bukan OS itu sendiri.

AntarmukaCara berinteraksiKeunggulanHal yang perlu diketahui
GUIGrafis, ikon, jendela, dan klik mouse.Ramah pengguna dan mudah dipelajari.Interaksi dilakukan lewat elemen visual.
CLITeks dan perintah yang diketik.Cepat dan powerful untuk menjalankan perintah.Perlu mengetahui atau menghafal perintah.
06BANYAK PROSES, SATU CPU

Multitasking & Round Robin

FAIRNESS

OS harus membagi waktu CPU di antara proses seperti musik, browsing, dan game. CPU tetap mengerjakan satu proses pada satu waktu, tetapi pergantian yang sangat cepat membuatnya terasa berjalan bersamaan.

QUANTUM TIME

Jatah waktu maksimal CPU untuk satu giliran proses.

BURST TIME

Waktu eksekusi yang dibutuhkan suatu proses.

ARRIVAL TIME

Waktu ketika proses tiba dan masuk antrean.

Musik→Browsing→Game↺Jika belum selesai, proses kembali ke ujung antrean setelah quantum.

Round Robin
Setiap proses mendapat jatah waktu sama dan bergiliran. Tujuannya fairness agar tidak ada proses yang diabaikan.

First Come, First Served
Jika game berdurasi panjang datang lebih dulu, musik dan browsing menunggu sampai game selesai. Sistem dapat terasa hang atau lambat.

08SISTEM YANG BEKERJA BERSAMA

Kolaborasi sistem komputer

INPUT → PROSES → OUTPUT
IoT

Internet of Things

Perangkat dan sensor terhubung internet untuk bertukar data. Contoh: sensor suhu gudang mengirim data ke server pusat.

CLOUD

Cloud computing

Layanan komputasi dan penyimpanan yang diakses melalui internet.

HPC

Supercomputer

Komputer berkemampuan sangat tinggi untuk simulasi besar, misalnya simulasi cuaca pada Sierra.

I/O

Interaksi manusia-komputer

Mengetik melalui keyboard adalah tahap Input; komputer memproses data dan menampilkan hasil sebagai Output.
